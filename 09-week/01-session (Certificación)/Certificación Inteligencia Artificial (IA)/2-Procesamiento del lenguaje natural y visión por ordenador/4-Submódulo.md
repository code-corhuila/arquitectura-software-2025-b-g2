# Módulo 4
## La IA clasifica las imágenes

### Introducción
En este módulo aprendí cómo la IA no solo analiza imágenes para identificar su contenido, sino que también puede crear imágenes creíbles por sí misma.

### Objetivos del curso
Después de completar este módulo, debería ser capaz de:

- Describir cómo la IA clasifica las imágenes para extraer su significado.  
- Describir cómo una red neuronal convolucional (CNN) analiza una imagen.  
- Describir cómo una red generativa adversarial (GAN) crea una imagen creíble.  
- Identificar los usos de la visión artificial en el mundo real.

### Redes neuronales convolucionales
Un sistema de IA utiliza una **red neuronal convolucional (CNN)** para analizar imágenes.  

Las fotos y vídeos digitales están compuestos por millones de píxeles, cada uno con niveles de luminosidad y color representables en números. Analizar millones de píxeles directamente sería abrumador para un sistema de IA. Para resolver esto, las CNN analizan pequeñas partes de la imagen a la vez, permitiendo identificar objetos, rostros y otros elementos visuales de manera eficiente.

Martin Keen, inventor maestro de IBM, explica cómo las CNN reducen el análisis de imágenes a una escala práctica.

### Redes generativas adversariales
Un sistema de reconocimiento visual puede utilizar una **red generativa adversarial (GAN)** para crear nuevos dibujos y fotos.  

Las GAN funcionan enfrentando dos redes neuronales: una genera imágenes y la otra las evalúa. A través de este "concurso", la red generadora mejora continuamente hasta producir imágenes que parecen reales, como los conocidos “deep fakes” o ilustraciones creadas por IA.

Martin Keen describe cómo las GAN logran generar imágenes creíbles mediante este proceso de competencia entre redes.

### Aplicaciones de la visión artificial
La visión artificial tiene muchas aplicaciones prácticas y útiles en el mundo real.  

Por ejemplo, el sistema de inspección visual **IBM Maximo** puede equiparse con cámaras en drones para supervisar estructuras como puentes. Este sistema no solo detecta problemas (como grietas), sino que también clasifica cuáles son peligrosos y requieren reparación inmediata, demostrando cómo la visión artificial puede mejorar la seguridad y eficiencia en tareas críticas.
